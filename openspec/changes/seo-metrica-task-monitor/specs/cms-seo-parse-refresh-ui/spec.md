# Spec Delta

## MODIFIED Requirements

### Requirement: Кнопка обновления на «Страницах» и «Запросах»
Кнопка «Обновить данные» SHALL находиться только в модальном окне задач привязанной Метрики; на «Страницах»/«Запросах» её MUST NOT быть. Кнопка MUST иметь доступное имя, быть доступной с клавиатуры и не перекрывать соседние элементы на 1366×768.

#### Scenario: Кнопка на двух вкладках
- **WHEN** SEO открывает «Страницы», «Запросы» и окно «Задачи» на «Интеграциях»
- **THEN** «Обновить данные» видна только внутри окна задач действующей привязки

#### Scenario: Раскладка 1366×768
- **WHEN** окно задач открыто в viewport 1366×768
- **THEN** кнопка, пагинатор и «Обновить список» не перекрываются и не выходят за область окна

### Requirement: Модалка подтверждения перед запуском
Нажатие «Обновить данные» SHALL открывать подтверждение над окном задач с пояснением о фоновой загрузке за последние дни и кнопками «Подтвердить»/«Отмена». Backend SHALL вызываться только после подтверждения. Закрытие подтверждения (Esc, крестик, «Отмена») MUST NOT отправлять запрос и MUST оставлять окно задач открытым.

#### Scenario: Отмена
- **WHEN** SEO нажимает «Обновить данные», затем «Отмена» либо Esc
- **THEN** запросов запуска нет, закрыто только подтверждение, фокус возвращается на «Обновить данные» внутри задач

#### Scenario: Подтверждение
- **WHEN** SEO нажимает «Подтвердить»
- **THEN** отправляется один POST /api/seo/parse-jobs с {"provider":"ya_metrica"}; в pending подтверждение не закрывается и повторные действия заблокированы

### Requirement: Результат запуска и ошибки
Успех 202 SHALL закрывать только подтверждение и показывать «Обновление поставлено в очередь», сбрасывать задачи к offset=0 и однократно перечитывать список. Окно задач SHALL оставаться открытым. POST MUST NOT повторяться автоматически; таблицы страниц/запросов MUST NOT перечитываться автоматически. Отображение задачи SHALL зависеть от доставки команды Метрике, а не от факта 202.

#### Scenario: Успех
- **WHEN** backend отвечает 202
- **THEN** подтверждение закрывается, уведомление видно, выполняется один GET задач с offset=0; нет повторного POST или перезапроса таблиц метрик

#### Scenario: Счётчик не привязан
- **WHEN** backend отвечает 400 с detail
- **THEN** подтверждение остаётся с безопасным detail, «Подтвердить» снова доступна; список задач не сбрасывается

#### Scenario: Сбой очереди
- **WHEN** backend отвечает 503 или сеть недоступна
- **THEN** подтверждение остаётся с «Не удалось поставить задачу, повторите позже» без тела ответа; повтор только явным нажатием

#### Scenario: RF-01 Eventual delivery
- **WHEN** после 202 первый GET ещё не содержит принятого job_id
- **THEN** UI не создаёт фиктивную persisted строку и поясняет «Задача появится после получения команды сервисом Метрики. Обновите список»; «Обновить список» доступно без повторной постановки

#### Scenario: RF-02 Остальные ошибки
- **WHEN** POST вернул 401/403/502
- **THEN** 401 запускает штатный auth flow, 403 показывает «Недостаточно прав», 502 — нейтральную ошибку постановки; нет ложного успеха/авторетрая

## ADDED Requirements

### Requirement: Матрица API окна задач
Окно SHALL использовать только CMS backend без браузерного tenant selector. GET SHALL быть чувствительным исключением Public Read: история внутренней обработки статистики доступна только SEO; POST SHALL сохранять Protected Write. Guard и double-submit защита SHALL действовать до вызова API, без role override.

#### Scenario: RF-03 Anonymous и authenticated
- **WHEN** API-boundary тесты вызывают операции без сессии, с SEO-only/SEO+ADMIN и без SEO
- **THEN** ответы соответствуют матрице, 401/403 отображаются без ложного успеха, отсутствие права блокирует действие локально

| method | path | access class | roles | expected without auth | expected with auth |
|---|---|---|---|---|---|
| GET | `/api/seo/metrica/tasks` | Protected GET exception | только SEO | 401 | 200; без SEO 403; invalid query 400; peer/DTO 502 |
| POST | `/api/seo/parse-jobs` | Protected Write | только SEO | 401 | 202; без SEO 403; тело/нет привязки 400; downstream 502; очередь 503 |
