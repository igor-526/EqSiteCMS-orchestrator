# Spec Delta

## MODIFIED Requirements

### Requirement: Кнопка обновления на «Страницах» и «Запросах»
Вкладки «Страницы» и «Запросы» SHALL показывать кнопку «Обновить данные» в блоке управления шапки рядом с пагинатором и «Сбросить»; на вкладках «Яндекс.Метрика» и «Яндекс.Вебмастер» кнопки нет. Кнопка MUST иметь доступное имя, быть доступной с клавиатуры и не перекрывать соседние элементы на 1366×768.

#### Scenario: Кнопка на двух вкладках
- **WHEN** SEO открывает вкладки «Страницы» и «Запросы»
- **THEN** кнопка «Обновить данные» видна в каждой, на остальных вкладках отсутствует

#### Scenario: Раскладка 1366×768
- **WHEN** страница открыта в viewport 1366×768
- **THEN** кнопка, пагинатор, «Сбросить» и «Нормализация» не перекрываются и не выходят за область заголовка

### Requirement: Модалка подтверждения перед запуском
Нажатие кнопки SHALL открывать модалку подтверждения с заголовком, пояснением (данные Метрики будут загружены в фоне за последние дни, таблица не обновляется мгновенно) и кнопками «Подтвердить»/«Отмена»; запрос на backend MUST отправляться только после подтверждения. Закрытие модалки (Esc, крестик, «Отмена») MUST NOT отправлять запрос.

#### Scenario: Отмена
- **WHEN** SEO нажимает кнопку, затем «Отмена» либо Esc
- **THEN** запросов к API нет, модалка закрыта, фокус возвращается на кнопку

#### Scenario: Подтверждение
- **WHEN** SEO нажимает «Подтвердить»
- **THEN** отправляется ровно один `POST /seo/parse-jobs` с `{"provider":"ya_metrica"}`, пока запрос идёт, модалка не закрывается, кнопки заблокированы

### Requirement: Доступ и защита от повторов
Действие SHALL требовать актуальный `SEO` без наследования ролей; без права кнопка и запрос недоступны (страница SEO и так закрыта для не-SEO). Hook MUST иметь синхронную защиту от повторного submit и guard перед вызовом API; в pending закрытие модалки и смена вкладки не отправляют второй запрос.

#### Scenario: Двойное подтверждение
- **WHEN** пользователь дважды быстро нажимает «Подтвердить»
- **THEN** отправляется один запрос

#### Scenario: Отзыв прав
- **WHEN** SEO отозван после отрисовки кнопки
- **THEN** hook не вызывает API, модалка не открывается

### Requirement: Access matrix потребляемого API
CMS SHALL вызывать только backend (не seo-service и не ya-metrica-service); tenant — из сессии, без selector из браузера.

#### Scenario: Контракт новой операции
- **WHEN** API-boundary тест вызывает операцию без сессии, с SEO и с другими ролями
- **THEN** фактические статусы соответствуют матрице

| method | path | access class | roles | expected without auth | expected with auth |
|---|---|---|---|---|---|
| POST | `/api/seo/parse-jobs` | Protected Write | только SEO | `401` (штатный refresh/login flow) | `202`; без SEO `403`; невалидное тело/нет привязки `400`; downstream `502`; очередь `503` |
