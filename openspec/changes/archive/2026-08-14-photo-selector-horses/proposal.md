## Why

В CMS существует универсальный компонент PhotoSelector для выбора главной фотографии, но его функционал не полностью реализован для лошадей. В настоящее время:

1. **Отсутствует выбор главной фотографии для лошадей** — в разделе "Лошади" (вкладка "Лошади") кнопка выбора фотографий не работает, хотя в эталонных разделах ("Услуги и цены", "Новости") эта функциональность полностью реализована.

2. **Присутствует лишняя логика для фотографий пород и мастей** — в разделах "Породы" и "Масти" заложены кнопки для работы с фотографиями, которые никогда не будут использоваться (по текущим требованиям фотографии пород и мастей не выводятся и не фильтруются).

Это создает несогласованность в пользовательском опыте и добавляет ненужную сложность в кодовой базе.

## What Changes

- **Реализация выбора главной фотографии для лошадей** — добавление полноценной работы PhotoSelectorModal для лошадей, аналогично эталонным разделам (Услуги и цены, Новости)
- **Удаление кнопок фотографий из таблицы пород** — удаление кнопки "Фотографии" из HorseBreedsTable и связанной логики
- **Удаление кнопок фотографий из таблицы мастей** — удаление кнопки "Фотографии" из HorseCoatColorsTable и связанной логики
- **Очистка backend логики** — проверка и удаление любого заложенного backend кода для фотографий пород и мастей (если существует)

## Capabilities

### New Capabilities

- `horse-photo-management`: Управление фотографиями лошадей с выбором главной фотографии через PhotoSelectorModal

### Modified Capabilities

(Нет изменений в существующих требованиях на уровне спецификаций)

## Impact

- **Frontend (services/frontend)**:
  - Модификация `/app/(protected)/horses/page.tsx` — добавление полной логики PhotoSelector для лошадей
  - Удаление пропсов `onOpenHorseBreedPhotosModal` из `HorseBreedsTable`
  - Удаление пропсов `onOpenHorseCoatColorPhotosModal` из `HorseCoatColorsTable`
  - Удаление связанных обработчиков и состояний в `horses/page.tsx`

- **Backend (services/backend)**:
  - Проверка отсутствия логики для фотографий пород/мастей (модель photos уже поддерживает только equestrian_id)
  - При наличии — удаление лишнего кода

- **Тесты**: Обновление тестов для компонентов таблиц пород и мастей

- **API**: Изменений в API не требуется (фотографии лошадей уже поддерживаются через существующие endpoints)
