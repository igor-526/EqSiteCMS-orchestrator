## MODIFIED Requirements

### Requirement: Инструкция и контрольная строка

Карточка MUST показывать инструкцию только после запроса привязки: при выданном коде либо PENDING; команда с кодом MUST отображаться моноширинно, копироваться полностью и сопровождаться временем истечения. До выдачи кода в состоянии «не привязан» инструкция и ссылка MUST отсутствовать.

#### Scenario: До запроса привязки инструкции нет

- **WHEN** карточка отрисована в состоянии «не привязан» и код ещё не выдан
- **THEN** инструкция и ссылка на диалог MUST отсутствовать

#### Scenario: Копирование команды

- **WHEN** пользователь нажимает кнопку копирования
- **THEN** в буфер обмена MUST попасть полная строка `<link_command> <code>`, а UI MUST показать подтверждение копирования

#### Scenario: Отображение срока действия

- **WHEN** код выдан с `expires_at`
- **THEN** карточка MUST показать срок действия в человекочитаемом виде

#### Scenario: Код истёк

- **WHEN** `expires_at` уже прошёл
- **THEN** карточка MUST пометить код недействительным и предложить обновить его

#### Scenario: Копирование недоступно

- **WHEN** Clipboard API недоступен в браузере
- **THEN** код MUST оставаться выделяемым текстом, а ошибка копирования MUST показываться без падения интерфейса

#### Scenario: Появление инструкции и формат контрольной строки

- **WHEN** карточка показывает состояние привязки и, при наличии, контрольную строку
- **THEN** Инструкция MUST появляться только после того, как пользователь запросил привязку: в состоянии «не привязан» без выданного кода карточка MUST NOT показывать ни инструкцию, ни ссылку на диалог, чтобы не нагружать пользователя шагами, которые ему ещё не нужны. Как только код выдан либо `state = PENDING`, карточка MUST показывать инструкцию: открыть диалог с ботом группы, отправить сообщение вида `<команда> <код>`, дождаться ответа бота. Контрольная строка MUST отображаться моноширинным шрифтом с кнопкой копирования в буфер обмена, копирующей полную строку команды вместе с кодом. Рядом MUST отображаться время истечения кода.

### Requirement: Внешняя ссылка на диалог с ботом

Карточка MUST показывать только внешнюю ссылку на диалог из `dialog_url` ответа `GET /api/vks/bot-info`, открывать её безопасно в новой вкладке и MUST NOT показывать `group_url`; предзаполнение текста MUST NOT быть обязательным.

#### Scenario: Атрибуты ссылки

- **WHEN** отрисована ссылка на диалог
- **THEN** она MUST иметь `target="_blank"` и `rel="noopener noreferrer"`

#### Scenario: Ссылка на сообщество отсутствует

- **WHEN** карточка отрисована в любом состоянии
- **THEN** ссылка на `group_url` MUST отсутствовать

#### Scenario: Источник ссылки

- **WHEN** карточка отрисована
- **THEN** адрес ссылки MUST приходить из `GET /api/vks/bot-info` и MUST NOT быть захардкожен в компоненте

#### Scenario: Данные бота недоступны

- **WHEN** `GET /api/vks/bot-info` возвращает `503` или ошибку
- **THEN** карточка MUST показать сообщение о незавершённой настройке VK, скрыть ссылку на диалог и MUST NOT блокировать остальные карточки страницы

#### Scenario: Назначение ссылки и ограничения VK

- **WHEN** карточка предоставляет внешнюю ссылку для подтверждения привязки
- **THEN** Карточка MUST показывать единственную внешнюю ссылку — на диалог с ботом (`dialog_url`), полученную из `GET /api/vks/bot-info`. Ссылка MUST открываться в новой вкладке с `target="_blank"` и `rel="noopener noreferrer"`. Ссылка на страницу сообщества (`group_url`) MUST NOT отображаться: привязка выполняется в личном диалоге, а переход в сообщество уводит пользователя от сценария. Ссылка на диалог SHOULD вести пользователя сразу в переписку с ботом; предзаполнение текста сообщения MUST NOT считаться обязательным, поскольку VK не поддерживает подстановку текста в ссылку на диалог.
