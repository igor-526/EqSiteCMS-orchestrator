# Spec Delta — yandex-oauth-cms-callback

## Purpose

OAuth-поток Яндекса в CMS: открытие ссылки авторизации в мини-окне, служебная callback-страница, обменивающая код на аккаунт через backend, и обновление списка аккаунтов в открывшем окне.

## ADDED Requirements

### Requirement: Запуск авторизации в мини-окне

Пункт «Добавить аккаунт» MUST получать ссылку `GET /api/yandex/auth/link` и открывать её в отдельном мини-окне (popup около 600×700, с сохранением `window.opener`). Пока поток активен, повторный запуск MUST фокусировать уже открытое окно, а не создавать новое.

#### Scenario: Открытие popup
- **WHEN** пользователь нажимает «Добавить аккаунт»
- **THEN** CMS запрашивает ссылку и открывает её в мини-окне, визард показывает состояние ожидания авторизации

#### Scenario: Popup заблокирован
- **WHEN** браузер заблокировал открытие окна
- **THEN** визард показывает сообщение о блокировке всплывающих окон и предлагает повторить

#### Scenario: Ошибка получения ссылки
- **WHEN** запрос ссылки завершился ошибкой
- **THEN** окно не открывается, визард показывает ошибку

### Requirement: Callback-страница OAuth Яндекса

CMS MUST иметь страницу `/callbacks/oauth/yandex` вне бокового layout, которая читает `code` и `state` из URL (прочие параметры, например `cid`, игнорируются) и выполняет ровно один `POST /api/yandex/auth/code` с `{code, state}`, показывая состояния обработки, успеха и ошибки.

#### Scenario: Успешный callback
- **WHEN** Яндекс перенаправляет на `/callbacks/oauth/yandex?state=<uuid>&code=<code>&cid=<cid>` в окне с активной сессией CMS пользователя ADMIN
- **THEN** страница отправляет POST с `code` и `state`, показывает успех с логином добавленного аккаунта

#### Scenario: Callback без ADMIN
- **WHEN** callback с валидными параметрами открывает authenticated пользователь без ADMIN, включая SUPERUSER/DEVELOPER
- **THEN** POST получает `403`, peer не вызывается, страница показывает отказ без `code` и не сообщает `success`

#### Scenario: Однократная отправка
- **WHEN** эффект страницы выполняется повторно (React StrictMode, повторный рендер)
- **THEN** POST с этим кодом отправляется ровно один раз

#### Scenario: Нет параметров
- **WHEN** в URL отсутствует `code` или `state`
- **THEN** POST не отправляется, страница показывает ошибку некорректной ссылки

#### Scenario: Отказ пользователя в Яндексе
- **WHEN** URL содержит `error` (например, `access_denied`) вместо `code`
- **THEN** POST не отправляется, страница показывает, что авторизация отменена

#### Scenario: Ошибка backend
- **WHEN** POST возвращает ошибку (`400`, `403` отсутствие ADMIN или несовпадение конюшни, `502`)
- **THEN** страница показывает безопасное сообщение ошибки и не показывает `code`

### Requirement: Уведомление окна-родителя и закрытие popup

После завершения обработки callback-страница MUST отправить окну-родителю сообщение `postMessage` с типом `eqsite:yandex-oauth` и статусом (`success`/`error`/`cancelled`) строго в `window.location.origin` и при успехе закрыть окно. Без `window.opener` страница остаётся открытой со ссылкой в раздел SEO.

#### Scenario: Popup с родителем
- **WHEN** обмен кода завершился успешно в popup
- **THEN** родитель получает сообщение `success`, popup закрывается

#### Scenario: Открыто без родителя
- **WHEN** страница открыта напрямую в обычной вкладке
- **THEN** результат отображается на странице со ссылкой «Перейти в раздел SEO», окно не закрывается

### Requirement: Обновление списка аккаунтов после авторизации

Визард MUST принимать только сообщения с `event.origin === window.location.origin` и типом `eqsite:yandex-oauth`; при `success` он перезагружает список аккаунтов с `offset=0`. Если popup закрыт без сообщения, визард MUST выйти из ожидания и перезагрузить список.

#### Scenario: Успешная авторизация
- **WHEN** визард получает сообщение `success` от своего origin
- **THEN** список аккаунтов перезагружается и содержит новый аккаунт, состояние ожидания снимается

#### Scenario: Чужой origin
- **WHEN** приходит сообщение с другим origin или иным типом
- **THEN** визард его игнорирует

#### Scenario: Окно закрыто вручную
- **WHEN** пользователь закрыл popup до завершения
- **THEN** визард снимает ожидание и перезагружает список без ошибки
