## Purpose
Определить хранение и применение статуса блокировки пользователей.

## Requirements

### Requirement: Механизм блокировки пользователей
Таблица `users` MUST содержать поле `is_blocked` (boolean, default=false, not null) для реализации блокировки пользователей.

#### Scenario: Поле существует в таблице users
- **WHEN** миграция Alembic применяется
- **THEN** таблица `users` содержит колонку `is_blocked` (boolean, default=false, not null)

#### Scenario: Дефолтное значение для существующих пользователей
- **WHEN** миграция применяется к существующим данным
- **THEN** все существующие пользователи имеют `is_blocked=false`

### Requirement: Блокировка пользователя
Операция блокировки MUST устанавливать `is_blocked=true` для указанного пользователя.

#### Scenario: Успешная блокировка
- **WHEN** вызывается операция блокировки для пользователя с `is_blocked=false`
- **THEN** `is_blocked` устанавливается в `true`

#### Scenario: Идемпотентность блокировки
- **WHEN** вызывается операция блокировки для пользователя с `is_blocked=true`
- **THEN** `is_blocked` остаётся `true`, операция считается успешной

### Requirement: Разблокировка пользователя
Операция разблокировки MUST устанавливать `is_blocked=false` для указанного пользователя.

#### Scenario: Успешная разблокировка
- **WHEN** вызывается операция разблокировки для пользователя с `is_blocked=true`
- **THEN** `is_blocked` устанавливается в `false`

#### Scenario: Идемпотентность разблокировки
- **WHEN** вызывается операция разблокировки для пользователя с `is_blocked=false`
- **THEN** `is_blocked` остаётся `false`, операция считается успешной

### Requirement: Заблокированный пользователь не может выполнять запросы к API
Пользователь с `is_blocked=true` MUST быть отклонён при попытке выполнить запрос к защищённым API-эндпоинтам.

#### Scenario: Заблокированный пользователь пытается выполнить запрос
- **WHEN** заблокированный пользователь (`is_blocked=true`) отправляет запрос к защищённому endpoint
- **THEN** backend возвращает `403 Forbidden` с сообщением "Пользователь заблокирован"

### Requirement: Заблокированные пользователи не попадают в выдачу сервисного endpoint
Сервисный endpoint `GET /api/service/users` MUST исключать пользователей с `is_blocked=true` из результатов.

#### Scenario: Запрос сервисного endpoint
- **WHEN** микросервис вызывает `GET /api/service/users`
- **THEN** в результат НЕ включаются пользователи с `is_blocked=true`

### Requirement: Индекс на поле is_blocked
Для оптимизации запросов MUST быть создан индекс на поле `is_blocked`.

#### Scenario: Индекс существует
- **WHEN** миграция применяется
- **THEN** на таблице `users` создан индекс для колонки `is_blocked`
