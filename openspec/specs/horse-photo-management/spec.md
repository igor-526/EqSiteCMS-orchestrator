# horse-photo-management Specification

## Purpose

Управление фотографиями лошадей с выбором главной фотографии через PhotoSelectorModal. Включает:
- Выбор главной фотографии для лошади через PhotoSelectorModal
- Удаление неиспользуемой логики фотографий для пород и мастей

## Requirements

### Requirement: Выбор главной фотографии для лошади
Система SHALL позволять выбирать главную фотографию для лошади через PhotoSelectorModal, аналогично эталонным реализациям в разделах "Услуги и цены" и "Новости".

#### Scenario: Открытие модального окна выбора фотографий
- **WHEN** Пользователь нажимает кнопку "Фотографии" в столбце "Действия" таблицы лошадей
- **THEN** Система открывает PhotoSelectorModal с текущими фотографиями выбранной лошади

#### Scenario: Просмотр списка фотографий
- **WHEN** PhotoSelectorModal открыт
- **THEN** Система отображает список всех доступных фотографий с возможностью прокрутки для подгрузки дополнительных фотографий

#### Scenario: Выбор главной фотографии
- **WHEN** Пользователь выбирает фотографию из списка в PhotoSelectorModal
- **THEN** Система устанавливает выбранную фотографию как главную для лошади и обновляет отображение

#### Scenario: Обновление списка фотографий
- **WHEN** Пользователь прокручивает список фотографий до конца
- **THEN** Система подгружает дополнительные фотографии через API

### Requirement: Удаление кнопки фотографий из таблицы пород
Система SHALL НЕ отображать кнопку "Фотографии" в таблице пород лошадей.

#### Scenario: Отсутствие кнопки фотографий в таблице пород
- **WHEN** Пользователь открывает вкладку "Породы" в разделе "Лошади"
- **THEN** Таблица пород НЕ содержит кнопку "Фотографии" в столбце "Действия"

#### Scenario: Отсутствие обработчика для фотографий пород
- **WHEN** Компонент HorseBreedsTable рендерится
- **THEN** Компонент НЕ принимает пропс onOpenHorseBreedPhotosModal

### Requirement: Удаление кнопки фотографий из таблицы мастей
Система SHALL НЕ отображать кнопку "Фотографии" в таблице мастей лошадей.

#### Scenario: Отсутствие кнопки фотографий в таблице мастей
- **WHEN** Пользователь открывает вкладку "Масти" в разделе "Лошади"
- **THEN** Таблица мастей НЕ содержит кнопку "Фотографии" в столбце "Действия"

#### Scenario: Отсутствие обработчика для фотографий мастей
- **WHEN** Компонент HorseCoatColorsTable рендерится
- **THEN** Компонент НЕ принимает пропс onOpenHorseCoatColorPhotosModal

### Requirement: Очистка неиспользуемых состояний и обработчиков
Система SHALL НЕ содержать неиспользуемые состояния и обработчики, связанные с фотографиями пород и мастей.

#### Scenario: Отсутствие неиспользуемых состояний
- **WHEN** Компонент HorsesPage рендерится
- **THEN** Компонент НЕ содержит состояния, связанные с фотографиями пород или мастей

#### Scenario: Отсутствие неиспользуемых обработчиков
- **WHEN** Компонент HorsesPage рендерится
- **THEN** Компонент НЕ содержит обработчики событий для фотографий пород или мастей
