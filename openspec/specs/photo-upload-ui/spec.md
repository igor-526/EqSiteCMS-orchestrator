## Requirements
### Requirement: Фиксированная сетка фотографий

Компонент PhotoSelectorList ДОЛЖЕН (SHALL) отображать фотографии в сетке ровно 4 элемента в ряд. Первый ряд ДОЛЖЕН (SHALL) быть всегда заполнен (если фотографий >= 4). Последний неполный ряд ДОЛЖЕН (SHALL) быть прижат к левому краю, а не растянут по всей ширине.

#### Scenario: Отображение 10 фотографий

- **WHEN** в списке доступно 10 фотографий
- **THEN** отображается 3 ряда: первые 2 ряда по 4 фотографии, третий ряд с 2 фотографиями прижат влево
- **AND** ширина карточек фотографий одинакова во всех рядах

#### Scenario: Отображение 3 фотографий

- **WHEN** в списке доступно 3 фотографии
- **THEN** отображается 1 ряд с 3 фотографиями прижатыми влево
- **AND** фотографии не растягиваются на всю ширину контейнера

#### Scenario: Отображение 8 фотографий (ровно 2 ряда)

- **WHEN** в списке доступно 8 фотографий
- **THEN** отображается 2 ряда по 4 фотографии
- **AND** оба ряда полностью заполнены

### Requirement: Кнопка загрузки фотографий

PhotoSelectorModal ДОЛЖЕН (SHALL) содержать кнопку "Загрузить" в секции "Добавить ещё". При нажатии кнопки ДОЛЖЕН (SHALL) открываться системный file picker для выбора одного или нескольких файлов изображений.

#### Scenario: Открытие file picker

- **WHEN** пользователь нажимает кнопку "Загрузить"
- **THEN** открывается системный диалог выбора файлов
- **AND** диалог позволяет выбрать несколько файлов (multiple)
- **AND** диалог фильтрует только файлы изображений (image/*)

#### Scenario: Отмена выбора файлов

- **WHEN** пользователь открывает file picker и закрывает его без выбора файлов
- **THEN** модальное окно PhotoSelectorModal остаётся открытым
- **AND** состояние списка фотографий не меняется

### Requirement: Загрузка выбранных файлов через batch upload+attach endpoint

После выбора файлов через file picker, система ДОЛЖНА (SHALL) загрузить все файлы на сервер одним запросом через entity-specific batch upload endpoint (`POST /{entity}/{id}/photos/upload`), который автоматически присоединяет загруженные фотографии к текущей сущности.

#### Scenario: Успешная загрузка одного файла к услуге

- **WHEN** пользователь выбирает 1 файл изображения в PhotoSelectorModal для услуги (price)
- **THEN** система отправляет `POST /prices/{price_id}/photos/upload` с FormData содержащим файл в `files[]`
- **AND** после успешного ответа (200) с `photos: [PhotoOutShortDto]` фотография появляется в секции "Выбранные фотографии"
- **AND** пользователь видит success notification "Загружено 1 фотография"

#### Scenario: Успешная загрузка нескольких файлов к лошади

- **WHEN** пользователь выбирает 3 файла изображения в PhotoSelectorModal для лошади (horse)
- **THEN** система отправляет `POST /horses/{horse_id}/photos/upload` с FormData содержащим 3 файла в `files[]`
- **AND** после успешного ответа (200) с `photos: [3 PhotoOutShortDto]` все фотографии появляются в секции "Выбранные фотографии"
- **AND** пользователь видит success notification "Загружено 3 фотографии"

#### Scenario: Partial success response (2 из 3 файлов)

- **WHEN** пользователь выбирает 3 файла, из которых 1 файл превышает допустимый размер
- **THEN** система отправляет `POST /{entity}/{id}/photos/upload` с 3 файлами
- **AND** получает ответ `200 OK` с `photos: [2 PhotoOutShortDto]` и `errors: [{index: 1, message: "File too large"}]`
- **AND** показывает success notification "Загружено 2 из 3 фотографий"
- **AND** показывает error notification для файла с индексом 1
- **AND** только 2 успешно загруженные фотографии появляются в "Выбранные фотографии"

#### Scenario: Полная ошибка загрузки всех файлов

- **WHEN** пользователь выбирает 2 файла, оба невалидны (не изображения)
- **THEN** система получает ответ `200 OK` с `photos: []` и `errors: [{index: 0, ...}, {index: 1, ...}]`
- **AND** показывает error notifications для обоих файлов
- **AND** секция "Выбранные фотографии" не меняется

### Requirement: Drag-and-drop загрузка

Секция "Добавить ещё" в PhotoSelectorModal ДОЛЖНА (SHALL) поддерживать drag-and-drop для загрузки файлов. Пользователь ДОЛЖЕН (SHALL) иметь возможность перетащить один или несколько файлов изображений из файлового менеджера операционной системы непосредственно на область списка доступных фотографий.

#### Scenario: Drag-over визуальная индикация

- **WHEN** пользователь начинает перетаскивать файлы над секцией "Добавить ещё"
- **THEN** область отображает визуальную индикацию (например, border или background change)
- **AND** индикация исчезает, когда пользователь покидает область без drop

#### Scenario: Успешный drop одного файла

- **WHEN** пользователь перетаскивает 1 файл изображения и отпускает его над секцией "Добавить ещё"
- **THEN** система загружает файл через `POST /{entity}/{id}/photos/upload`
- **AND** после успешной загрузки фотография появляется в "Выбранные фотографии"
- **AND** пользователь видит success notification

#### Scenario: Drop нескольких файлов

- **WHEN** пользователь перетаскивает 5 файлов изображений и отпускает их над секцией "Добавить ещё"
- **THEN** система загружает все файлы одним запросом `POST /{entity}/{id}/photos/upload`
- **AND** показывает success notification "Загружено 5 фотографий" (при успешной загрузке всех)
- **AND** все загруженные фотографии появляются в "Выбранные фотографии"

#### Scenario: Drop не-изображения

- **WHEN** пользователь перетаскивает файл не-изображение (например, .pdf или .txt)
- **THEN** система показывает error notification "Поддерживаются только файлы изображений"
- **AND** файл НЕ загружается на сервер
- **AND** список фотографий не меняется

#### Scenario: Drop файлов во время активной загрузки

- **WHEN** пользователь drop файлы A и B, затем сразу drop файл C до завершения загрузки A и B
- **THEN** показывается loading indicator "Файлы уже загружаются, подождите..."
- **AND** новый drop игнорируется до завершения текущей загрузки
- **AND** после завершения первой загрузки пользователь может drop снова

### Requirement: Обратная совместимость с существующим функционалом

Все существующие возможности PhotoSelectorModal ДОЛЖНЫ (SHALL) продолжать работать после добавления upload UI:
- Добавление фотографий из галереи (клик на PlusOutlined)
- Удаление фотографий из выбранных (клик на MinusOutlined)
- Установка главной фотографии (клик на StarOutlined)
- Infinite scroll для подгрузки дополнительных фотографий из галереи
- Фильтрация выбранных фотографий из списка доступных

#### Scenario: Добавление из галереи после upload

- **WHEN** пользователь загрузил 2 фотографии через upload, затем добавляет 1 фотографию из галереи
- **THEN** все 3 фотографии отображаются в "Выбранные фотографии"
- **AND** можно установить главную фотографию среди любой из 3

#### Scenario: Upload во время открытого PhotoSelectorModal

- **WHEN** пользователь открывает PhotoSelectorModal с уже выбранными 5 фотографиями
- **THEN** секция "Выбранные фотографии" показывает 5 фотографий в сетке 4+1
- **AND** кнопка "Загрузить" доступна
- **AND** пользователь может загрузить дополнительные фотографии

#### Scenario: Infinite scroll не ломается после добавления upload UI

- **WHEN** пользователь прокручивает список доступных фотографий до конца
- **THEN** автоматически подгружаются следующие 25 фотографий
- **AND** drag-and-drop зона остаётся активной
- **AND** сетка продолжает отображать 4 фотографии в ряд
