# Ответы на открытые вопросы
  1. Нужна ли пользовательская авторизация для send-confirmation.
     Нет. email сервис по контрольной строке сопоставляет email для подтверждения и пользователя
  2. Какой контракт межсервисной авторизации использовать для email-service.
	  Межсервисная авторизация не требуется. Суть в том, что все сервисы, кроме основного backend доступны друг для друга только в локальной сети. При обращении сервиса к основному backend должны использоваться эндпоинты с `/service/` путём и специальным сервисным ключом
  3. Оставлять ли название X-Equestrian-Service-Key или заменить на tenant-oriented.
     Нет, оставь. Оно и так работает хорошо
  4. Какой HTTP-статус возвращать при отсутствующем/неверном tenant selector.
     401
  5. Какая минимальная матрица реальных NATS/Celery integration-тестов обязательна.
     На твоё усмотрение, чтобы было достаточно
