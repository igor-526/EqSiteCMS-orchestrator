# Заполнение описаний услуг

## Контекст

На страницах услуг есть область для текста, которая либо пустая, либо не редактируется

## Группы услуг

### Занятия

URL: /uslugi/zanyatiya

После заголовка "Занятия и абонементы" есть пустая область до блока "Стоимость"

### Прогулки

URL: /uslugi/progulki

После заголовка "Прогулки" есть пустая область до блока "Как проходит прогулка", после которой есть так же пустая область

Необходимо избавиться от блока "Как проходит прогулка". Будем задействовать только блок после основного заголовка

### Постой

URL: /uslugi/postoy

Избавляемя от блоков "Инфраструктура" и "Что входит". Будем задействовать только блок после основного заголовка "Постой"

## Задача

Страницы загружаются на основе фильтрации по группе услуг. У самой группы услуг есть описание. Вместо пустого пространства должен отображаться текст, который администратор вводит в CMS в описании группы услуг. От остальных блоков избавляемся и будем их реализовывать только по согласованию
