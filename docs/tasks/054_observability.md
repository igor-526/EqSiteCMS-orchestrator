# Контекст
Вручную были настроены Sentry и Prometheus для основного backend и их сервисов
Нужно проверить корректность внедрения, запротоколировать его и внедрить для frontend
# Frontend
Внедри Sentry в основной frontend и в consumer сайт
Используй те же наименования переменных, что и для backend
Учитывай в Dockerfile и Makefile особенности сборки контейнера и прокидывания переменных
Заполни только `.env` и `.env.example` в frontend проектах
# Проверка и протоколирование
Проверь корректность внедрения Prometheus и Sentry для backend и его сервисов. Должно быть однообразно и соответствовать SOLID
Запротоколируй использование инструментов мониторинга Sentry и Prometheus
