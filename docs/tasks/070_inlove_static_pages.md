# Задача
Используя схему сайта реализуй следующие страницы:
- Главная
- Новости (включая генератор страниц для каждой новости по slug в пути в соответствие с работой API CMS бэкэнда)
- О клубе
Помни об адаптивности как для компьютеров и планшетов, так и для мобильных устройств
Помни о том, что весь контент страницы должен быть отрендерен на стороне сервера для обеспечения лучшего SEO experience
# Промежуточная заметка
Ты потратил на эту задачу три пятичасовых лимита и так и не завершил её. Завершай задачу на бэке в более щадящем режиме. По сайту есть следующие недостатки:
## Главная страница
### Главный блок
На фоне на данный момент градиент. Найди красивую фотографию в материалах и поставь её на фон
### Блок перехода к услугам
Реализуй его в виде 4-х квадратных карточек. Сгенерируй подходящие иконки
### Блок стоимость
Убираем полностью
### Блок новости
Сделай  в БД mock данные. 3 любые новости
### Блок контакты
1. ВКонтакте переименуй на VK
2. Сделай 3 строки для трёх контактов. Для каждой поставь подходящую иконку из пака или найти в интернете и сделай статикой
3. Кнопку "Записаться" переименуй на "Обратный звонок"
4. Карта на данный момент недоступна. Посмотри на реализацию карты на главной странице сайта aleksandrova-dacha и реализуй аналогичным способом. Должна настраиваться из site-settings
5. Все ссылки должны открываться в новых вкладках
## Страница "О клубе"
Убери блок "Способы оплаты"
Текст должен браться из site-settings бэкэнда. Сгенерируй красивый правдоподобный текст
Блок обработки персональных данных тоже не нужен
Контакты оставь как переиспользуемый с главной страницы
