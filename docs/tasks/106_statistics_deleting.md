# Удаление SEO сущностей
## Контекст
На данный момент есть возможность отвязать от конюшни аккаунт Яндекс и отвязать от конюшни счётчик Яндекс.Метрика
Нам необходимо разработать эталонное поведение
## Удаление счётчика
При удалении счётчика Яндекс.Метрика необходимо удалять все полученные с его помощью статистики. Так как статистик может быть слишком много, мы не можем делать удаление метрик по конюшне одним запросом. Давай сделаем следующим образом:
1. При удалении счётчика `yandex-service` в NATS шлёт увеломление о необходимости очистки данных конюшни
2. Сервис `ya-metrica-service` читает stream и ставит в очередь задачу на удаление всех статистик
3. Удаление статистик происходит батчами, не все сразу, так как их может быть миллион и более записей
### UI
Удаление счётчика должно происходить только через модальное окно с подтверждением
## Удаление аккаунта Яндекс
При удалении аккаунта Яндекс автоматически должен удаляться счётчик Яндекс.Метрика со всеми вытекающими последствиями. То есть при удалении аккаунта Яндекс автоматически удаляются и все статистики Яндекс.Метрика
### UI
Удаление аккаунта Яндекс должно происходить только через модальное окно с подтверждением
## Подтверждающее модальное окно
В подтверждении необходимо написать все последствия и действия, которые потом необходимо будет предпринять для восстановления данных
Кнопка подтверждения должна быть активна только через 5 секунд после появления модального окна. В кнопке подтверждения необходимо в скобках отобразить таймер обратного отсчёта
Формулиурй предупреждение в виде перечисления данных, которые будут потеряны, так как позже могут быть добавлены новые интеграции. В таком случае гораздо проще будет просто добавить в список пункты
## Новые парсинги
Необходимо обработать следующую ситуацию:
Пользователь удаляёт счётчик или аккаунт Яндекс, после чего сразу же привязывает, а воркер ещё не успевает полностью удалить все старые данные
Давай сделаем следующим образом: задание на парсинг не будет выполняться, пока есть задания на удаление данных в рамках конюшни
## Текущие парсинги
Может произойти такая ситуация, что пользвоатель удаляет аккаунт или счётчик прямо во время парсинга. В таком случае необходимо перед удалением сначала прекратить парсинг, убрав из очереди все задания конюшни в ожидании, а остальные дать доделать
