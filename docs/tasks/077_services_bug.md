# Получение услуг на production

## Описание бага

Мы работаем с сайтом конюшни inlove. Его локальная версия работает хорошо, все услуги грузятся. Production версия не загружает услуги и выдаёт ошибки:

* Услуга «Занятия» временно недоступна.
* Услуга «Прогулки» временно недоступна.
* Услуга «Постой» временно недоступна.

При этом другой фунционал, связанный с backend работает корректно - настройки сайта, новости, обратный звонок и тд
