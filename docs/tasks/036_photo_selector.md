# Контекст
В frontend cms есть универсальный фото селектор. Но не везде можно выбрать главную фотографию
# Места использования
- Раздел "Лошади", вкладка "Лошади", столбец "Действия", первая кнопка. Не реализован функционал выбора главной фотографии
- Раздел "Услуги и цены", вкладка "Цены и услуги", столбец "Действия", вторая кнопка. Эталон
- Раздел "Новости", вкладка "Новости", столбец "Действия", вторая кнопка. Эталон
## Необходимо избавиться
Есть заложенная кнопка в таблицах в следующих разделах:
 - Раздел "Лошади", вкладка "Породы", столбец "Действия", первая кнопка
- Раздел "Лошади", вкладка "Масти", столбец "Действия", первая кнопка
Фотографии по ним по отдельности никогда не будут выводиться и фильтроваться. Потом будет реализована фильтрация по лошадям. На данный момент это NON-GOAL
# Логика
Посмотри для эталонных разделов логику работы с фотографиями и главной фотографией
# Задача
Реализуй изменения в основном backend и frontend cms. Изменения в consumer проектах не потребуются
## Фотографии лошадей
Необходимо реализовать аналогичную логику с выбором главной фотографии у лошади, как это реализовано в услугах и новостях
## Избавиться от лишней логики
Посмотри, нет ли заложенной на backend и frontend логики под фотографии для пород лошадей или масти лошадей. Если есть, то от неё необходимо полностью избавиться
Не забудь посмотреть UI галереи
