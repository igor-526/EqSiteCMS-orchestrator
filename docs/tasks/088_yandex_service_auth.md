# Авторизация пользователя в сервисах Яндекс
## Контекст
В задаче `087_yandex_service` был инициализирован пустой сервис Яндекс
Сейчас нам нужно реализовать авторизацию пользователя в CMS
## Пайплайн
1. Пользователь нажимает на кнопку "Выбрать аккаунт"
2. В открывшемся модальном окне пользователь нажимает на кнопку "Новый аккаунт"
3. В мини-окне открывается подтверждение авторизации Яндекс
4. Пользователь подтверждает авторизацию
5. Мини-окно автоматически закрывается
6. В модальном окне в списке появляется новый аккаунт
## Инфраструктура
После успешной авторизации через Яндекс аккаунт в мини-окне, Яндекс сделает redirect на свою страницу. В параметрах ссылки будет код, с помощью которого можно получить авторизационные токены
Frontend с этой страницы делает запрос на backend с указанием этого кода в body запроса. Backend маршрутизирует этот запрос в сервис Яндекса
Сервис яндекса получает access, refresh токены и информацию о пользователе
Сервис яндекса отвечает на запрос backend
Backend отдаёт ответ на frontend
Frontend закрывает мини-окно и обновляет список доступных для выбора аккаунтов
## CMS Frontend
В боковом меню добавь кнопку "SEO". Найди подходящую для этого иконку из доступных библиотек
При нажатии на эту кнопку открывается страница. Структура аналогичная настройке уведомлений - вкладки
Первой вкладкой сделаем настройки. Расширять её будем в других задачах
В этой задаче пусть там будет только одна кнопка "Настроить"
При нажатии на эту кнопку должно открыться модальное окно с выбором аккаунтов и нажатием на кнопку "Добавить новый"
При нажатии на "Добавить новый" должно открыться мини-окно с авторизацией Яндекс
При успешной авторизации frontend делает POST запрос на основной backend
## Привязки и роли
Необходимо в основном backend создать роль "seo". Без этой роли пользователю недоступна страница "seo"
Сами аккаунты привязываются не к авторизованному пользователю, а к конюшне в целом
То есть любой пользователь с ролью seo может управлять привязками
## Роутинг запросов
В конкретно этом случае основной backend выполняет проксирование запросов к Яндекс сервису, а не к SEO сервису
