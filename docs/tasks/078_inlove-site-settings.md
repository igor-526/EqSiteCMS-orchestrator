# Настройки сайта в CMS для Inlove

## Контекст

Нам нужно доработать пул настроек для сайта, доступных для редактирования администратором конюшни

## Описания

Для всех site-settings нужно убрать описание полностью

## contacts.coordinates

На данный момент представлен в виде json файла и нужен для отображения карты на главной странице и в footer сайта. Давай переделаем на 2 значения `contacts.map.latitude` и `contacts.map.longitude`

## contacts.maps\_url

Для похожей с описанным пунктом выше семантикой давай использовать ключ `contacts.map.url`

## contacts.nearest\_stop

Проверь необходимость использования этого ключа. Если эта настройка нигде не используется, то от неё необходимо избавиться

## contacts.working\_hours

Проверь необходимость использования этого ключа. Если эта настройка нигде не используется, то от неё необходимо избавиться

## Контакты

Давай добавим на главную страницу и в подвал под адресом информацию о рабочем режиме в будни и выходные
Давай добавим для этого следующие ключи:

* `contacts.hours.weekdays.start` - начало работы в будние дни
* `contacts.hours.weekdays.stop` - окончание работы в будние дни
* `contacts.hours.weekend.start` - начало работы в выходные дни
* `contacts.hours.weekend.stop` - окончание работы в выходные дни
  Посмотри ограничения ключей. Если не влезаем - предложи альтернативы. Миграцию не будем делать

## Задача

Реализуй корректную работу этих настроек локально. Записи будут переноситься на боевую БД самостоятельно
