# Значки

Эти индикаторы разные. Мне больше нравится индикатор, который у кнопки управления связями с услугами. Единственное я бы хотел поменять цвет бейджа с красного на серый
# Модальное окно создания и редактирования связи
## Сортировка
Нажатие кнопки вызывает Drawer с таблицей связанных с лошадью услуг. Эти связи отсортированы по UUID. Давай сделаем стандартную сортировку по `-created_at`. Если этого поля на данный момент нет в БД, то необходимо сделать миграцию и добавить (все текущие связи можно дропнуть перед миграцией. Она ещё не на проде) или заполнить как `now()`
## Заполнение
При нажатии на кнопку добавления связи появляется модальное окно, в котором необходимо выбрать услугу и есть возможность ввести переопределения описания и цены услуги. При выборе в селекторе услуг услуги эти поля при создании остаются пустыми. Я бы хотел, чтобы 
при выборе услуги поля описания и цены автоматически заполнялись наследуясь от выбираемой услуги. То есть чтобы пользователь при выборе в селекторе услуги видел в этих полях информацию, которая задавалась при создании услуги
