# Контекст
В задачах с префиксом inlove мы реализовывали функционал сайта для конюшни. Сейчас осталось несколько доработок
# Доработки
## Header
В компьютерной версии в меню точкой показывается активный пункт меню. На данный момент точка показывается поверх текста пункта, а не под ним
## Footer
Аналогичная проблема с меню
Мне не нравится дизайн подменю "Услуги". Убери выделение рамкой и стрелочку "вправо" слева от "УСЛУГИ". Оставь только отступы
## Главная страница
В контактах есть карта. Необходим небольшой отступ сверху, так как она сейчас прилипает к верхнему блоку
## Другие страницы
Есть страницы, которые завершаются зелёным блоком. Например, /uslugi/zanyatiya. В зелёных блоках заголовок слишком близко к началу блока. Необходимо добавить расстояние (разумное)
Кнопки в зелёных блоках неочевидны. Давай для них оставим цвет, но добавим белую окантовку
