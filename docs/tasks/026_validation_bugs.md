## Пустой slug
В форме модального окна на создание или изменение породы при отсутствии slug (Путь в URL) выдаётся ошибка "Slug не может быть пустым". Запрос при этом происходит, ошибка возвращается с сервера. При пустом slug он должен быть сгенерирован автоматически (как в price)
## Пустое описание породы
В форме модального окна на создание или изменение породы при отсутствии описания породы выдаётся ошибка "Описание породы не может быть пустым". Запрос при этом происходит, ошибка возвращается с сервера. Это некорректное поведение. Описание породы может быть пустым
