# Улучшение галереи
## Контекст
На данный момент пользователь может добавить в галерею фотографии. В галерее есть фильтры по породе, масти, лошади и тд. На данный момент эти фильтры неактивны. Я придумал более интересный способ добавления фотографий
## Концепция
Мы поделим окно на 2 части. Слева дерево, справа фотографии
На первом уровне папка "Вся галерея"
В ней папки:
 - услуги
 - лошади
 - новости
 При открытии одной из папок открывается третий уровень
