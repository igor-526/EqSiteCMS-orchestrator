## Контекст
В предыдущих задачах мы выполняли комплек задач, направленных на следующий функционал:
- парсинг данных Яндекс.Метрика
- планирование SEO задач
- вывод метрик
- задачи по слиянию страниц после нормализации
- задачи по удалению метрик после удаления счётчика или аккаунта
Не очень удобно то, что мы теперь не можем отследить статус выполнения задач
## Задачи
### Слияние вкладок
На данный момент в разделе SEO есть вкладки Яндекс.Метрика и Яндекс.Вебмастер
Во второй стоит просто заглушка о том, что функционал находится в разработке
На первой есть блок для интеграции с Яндекс.Метрика
Давай во-первых переименуем его в "Яндекс.Метрика" без слова "Подключения"
Во вторых назовём эту вкладку "Интеграции", а вкладку "Яндекс.Вебмастер" просто удалим
### Кнопка задач
При активной привязке счётчика давай сделаем кнопку "Задачи". При нажатии на эту кнопку должно открываться модальное окно с активными и завершёнными задачами
Интересует следующий тип задач:
- парсинг метрик
- слияние метрик страниц
- удаление данных
По сортировке наверху всегда активные задачи. Вторая сортировка -created_at
По парсингу сервис метрики декомпозирует задачи на несколько. В этой таблице запись должна быть только одна
Так как этот список задач является только задачами метрики, я бы хотел, чтобы они брались по API с сервиса метрики
Учти пагинацию
