# Реализация frontend для SEO сервиса

## Контекст

В задаче 099 мы реализовывали функционал SEO-сервиса. Хранение поисковых запросов и страниц для конюшни, а также эндпоинты для получения страниц и поисковых запросов

Дополнительно было реализовано API управления нормализацией страниц при сохранении

В задаче 098 мы реализовывали frontend для управления аккаунтами Яндекс и управления привязкой счётчика Яндекс.Метрика

## Задачи

### Вкладки в разделе SEO

В созданном SEO разделе есть только вкладки для управления метрикой и вебмастером. Давай добавим вкладки "Страницы" и "Запросы". В этих вкладках реализуем таблицы с запросами и страницами. Эталоны табличного представления есть в дургих разделах сайта. На данном этапе мы только отображаем доступные страницы и запросы. Позволяем фильтровать и сортировать. ФИльтрацию и сортировку реализовывай только в шапке таблицы. Вверху только пагинация

### Управление нормализацией

На вкладке страниц давай добавим кнопку "Нормализация". При нажатии должно открываться модальное окно. В модальном окне мы делаем вкладки как в разделе "Хеш" и "Параметры". Ниже мы оформляем пагинированный список из значений для фильтрации. В списке должны быть компактные элементы. Справа от элемента кнопка удадения в виде иконки. Удаление только через модальное окно с подтверждением. Выше списка делаем input и справа от него иконка плюсика. Этот input добавляет новое значение для фильтрации
