# Задача
## Уборка материалов
В материалах убери всё от Tilda
## Сидинг данных
Исходя из доступной информации сделай для конюшни сид данных
Используй генератор UUID, не надо делать по типу "00000-..."
В качестве сервисного ключа для конюшни используй `inlove`
Оставь сид данных в `docs/sites/inlove/seed.sql`. Не применяй
## Спецификация дизайна
При необходимости доработай файл
Доработай Frontend CMS агента таким образом, чтобы эта спецификация была для него инструкцией
## Схема сайта
Постарайся подробнее описывать эндпоинты, которые будут задействоваться и какие данные где будут расположены. Используй CMS по максимуму
### обогащение
Нам необходимо обогатить файл схемы сайта
Посмотри API бэкэнда, посмотри пример сайта `aleksandrova-dacha` в плане его работы с API CMS бэкэнда
Я сделал пример главной страницы. По примеру обогати информацией остальные страницы. Схему не меняй
Продумай десктоп и мобильную версию
### header и footer
 Обогати схему сайта описанием header, который будет на каждой странице
 В header будет логотип, являющйся ссылкой на главную, главное меню и блок контактов
 Обогати схему сайта описанием footer, которое будет на каждой странице
 Продумай десктоп и мобильную версию
### форма обратной связи
Обогати схему сайта формой обратной связи. Эта форма может быть вызвана в любом месте сайта и она должна быть универсальна
## Элементы
Исходя из обогащения схемы сайта составь список примитивных компонентов, из которых будут собираться страницы. Сделай описания этих элементов
Положи итоговый файл в `docs/sites/inlove/components.md`
