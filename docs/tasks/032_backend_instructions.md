# Контекст
В задаче 031_NATS_Jetstream_protocols.md мы протоколировали разработку NATS. В результате документ оказался не там, где я его ожидал
# Структура
Сейчас основной агент оркестрирует другими агентами на основании инструкции в `AGENTS.md`
Я хочу, чтобы в этой же папке были другие инструкции по работе профильных агентов с другими технологиями. По сути протоколы. Но при этом я не хочу, чтобы в контексте агентов были инструкции по модулям, с которыми агенту не нужно работать
Для решения этой проблемы давай в папке агентов создадим папку с такими протоколами и инструкциями, а в файлах профильных агентов сделаем на эти файлы ссылки, чтобы профильные агенты брали в контекст эти инструкции только тогда, когда это явно требуется. На примере NATS это нужно только для QUALITY_GATE и BACKEND
