## DeepSeek Harness
В проекте необходима отдельная переносимая копия DeepSeek Harness. Установи её в корень только для этого проекта. Тут будут плагины. Отредактируй .gitignore таким образом, чтобы сам dsh можно было установить одной или несколькими командами, а плагины и прочие настройки могли быть переносимыми на другую рабочую машину. Дальнейшая настройка будет выполняться из самого dsh
