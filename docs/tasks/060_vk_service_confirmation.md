# Контекст
В задаче `059_vk_service_initialization` мы инициировали сервис для работы с VK
Наша текущая задача будет реализовать механики подтверждения пользователей ВК
# Библиотека для работы
Наш сервис будет одновременно и ботом. Для начала давай реализуем только long-polling тактику
Выбери хорошую асинхронную поддерживаемую библиотеку для использования инструментария VK
# Пайплайн для подтверждения
Пользователь в настройках уведомлений видит блок с настройками VK
В этом блоке есть ссылка на группу ВК, в которой есть бот и сообщение в виде, команды, которое нужно отправить для подтверждения. Пользователь отправляет боту сообщение со строкой-кодом. Сервис сверяет код и привязывает id в VK к id пользователя
# Состояние пользователей
Держи состояние Active, Blocked и тд
Нужно обрабатывать корректно, если пользователь заблокирует бота
# Backend
Реализуй работу с пользователями и с привязками к VK по аналогии с email севрисом
Пользователь может привязать ВК и отвязать его. Также настроить уведомления
# Frontend
В разделе настройки уведомлений по аналогии с настройкой email создай блок для настройки VK. Этот блок должен содержать информацию о том, привязан ли VK к пользователю или нет. По аналогии все действия с почтой. Если VK не привязан, пользователю необходимо показать информацию о том, как привязать. Все ссылки должны открываться в новых вкладках. В идеале, если получится сделать ссылку, которая будет сразу направлять пользователя в диалог с уже собранным сообщением боту
