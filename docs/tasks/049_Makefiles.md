# Контекст
Мы готовимся к однородному CI. Я хочу, чтобы во всех проектах был Makefile с командами для CI
# Команды
В следующих сервисах:
- `backend`
- `frontend`
- `notification-service`
- `email-service`
Проконтроллируй наличие нижеперечисленных команд
consumer sites не трогаем
В корневом `Makefile` оркестратора должны быть эти же команды. Они должны проходиться по всем сервисам (в явном виде, не циклом) и выполнять эти команды
## test
При команде `make test` должно проводиться тестирование проекта. Эта команда будет выполняться в воркере GitHubActions. Учти, что там не будет инфраструктуры
## lint
При команде `make lint` должен проводиться линтинг всего кода
## format
При команде `make format` должно проводиться форматирование всего кода
# Задача
В каждом из перечисленных сервисов проконтроллируй наличие Makefile и корректность работы этих команд
Добавь их в файлы агентов как необходимость для контроля качества
