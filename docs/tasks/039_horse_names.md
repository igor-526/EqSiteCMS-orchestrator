# Контекст
Мы реализовывали задачу `025_horse_codes`, в которой добавляли возможность указать код родословной. Теперь нам нужно изменить production данные. Мы это будем делать в 2 этапа. После первого этапа обязательна остановка для согласования заменяемых данных
# Этап 1
В `docs/tasks/039_horse_names/horse.json` выгружены все лошади из БД. Обычно лошадей называют только одним словом, но есть исключения. Там же в кличке попадаются страны этих лошадей. Твоя задача будет изучить информацию в интернете о коде родословной, после чего в директории `docs/tasks/039_horse_names` сделать файл `horse_with_codes.json`, в котором нужно выполнить корректный экстракт кода родословной из клички лошади. В этом json используй только поля id, клички и кода. Записывай туда только тех лошадей, которых мы будем изменять
# Этап 2
Из получившегося файла сделай в этой же директории одноразовый SQL скрипт, который обновит всех лошадей, которые изменялись
