# Баг
Consumer Frontend отдаёт заголовок, который содержит кодовое наименование конюшни, на которую пришла заявка на обратный звонок. При тестировании выяснилось, что заявка попадает корректно на конюшню, API работает тоже корректно в контексте конюшни, но уведомление пришло пользователям, которые не являются пользователями конюшни
# Задача
В одной из задач мы реализовывали сервисный эндпоинт, который обрабатывает запрос микросервиса на предоставление пользователей. Одним из фильтров является конюшня. Событие оставляет эту информацию в NATS. Микросервис уведомлений должен воспользоваться этим эндпоинтом, чтобы забрать пользователей конкретной конюшни для события заявки обратного звонка. Уведомление не должно приходить всем пользователям, это некорректное поведение
