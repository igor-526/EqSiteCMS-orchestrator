# Контекст
С прошлого рефакторинга мы проделали много работы. Неплохо было бы сейчас проанализировать, что есть и выполнить глобальный рефакторинг и QualityGate.
# Задача
Необходимо прочитать агентов `backend` и `frontend` внимательно, а также все файлы с протоколами howto. Профильным агентам дать задание пройтись по всему проекту (а в случае с backend нужно пройтись по всем микросервисам отдельными субагентами)
Не трогаем только Frontend Consumer
Нужно выявить несоответствия в проекте с архитектурой, SOLID, правилами. Прогнать все тесты, все линтеры, все форматтеры
Для этой задачи мы не будем использовать OpenSpec. Мы будем составлять план доработок в `docs/plans`. Создай там файл `044_deep_refactoring.md`, в котором укажи все места, требующие исправления. Согласно этому плану мы будем выполнять рефакторинг. Не приступай к реализации до согласования плана. После выполнения всех правок нам нужно провести глобальный QualityGate, который проверить исправления всех выявленных недочетов и проверит работоспособность проекта путём пересборки всех образов и перезапуска контейнеров.
В рамках QualityGate глобальный линтинг, тестирование, SMOKE тестирование, e2e тестирование, форматтинг
