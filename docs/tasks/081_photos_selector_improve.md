# Доработка селектора фото
## Контект
На данный момент мы можем добавить фотографии к услуге, новости, лошади
Для этого на cms frontend переиспользуется одна и та же форма. Мы её и будем дорабатывать
## Вёрстка
Там есть 2 блока фотографий:
- выбранные
- доступные для выбора
Они раскидываются по всей ширине, если в ряду мало фотографий и это визуально неудобно
Давай сделаем сетку по 4 фотографии в ряд. Первый всегда заполнен, а последний не раскидывается по всей ширине, а прижимается слева
## Добавление фотографий
Очень неудобно реализован функционал. Для добавления фотографии для сущности необходимо загрузить её сначала в галерею, потом уже в сущности выбирать
Давай добавим кнопку "Загрузить". При нажатии открывается filepicker для фотографий и пользователь может выбрать одну или несколько фотографий. После выбора они автоматически загружаются и присоединяются к сущности. Также нужна поддержка dnd
