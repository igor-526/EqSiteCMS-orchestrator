# Задача
У нас сейчас есть только 1 тип уведомлений - заявка на обратный звонок. Сейчас уведомления на email доходят корректно. Теперь нам нужно реализовать доставку уведомлений о заявке на обратный звонок в VK и провести тестирование
Обрати внимание, в задаче 055 мы реализовывали механики работы с заявками на обратный звонок и там есть механизм, который ставит флаг доставки уведомлений на запись заявки на обратный звонок. Эта механика применима и к доставке уведомлений в VK
Для тестирования почты считай, что уведомление доставлено в случае отправки без контроля доставки
Для VK можешь спрашивать у меня
VK привязан к профилю admin
Протестируй следующие кейсы:
- пользователь не является администратором конюшни - сообщение не должно быть доставлено ни на почту, ни в вк
- пользователь привязан к другой конюшне, но может являться администратором - сообщение не должно быть доставлено ни на почту, ни в вк
- пользователь отключил доставку уведомлений в вк или на почту - уведомление в соответствующий канал не должно быть доставлено
