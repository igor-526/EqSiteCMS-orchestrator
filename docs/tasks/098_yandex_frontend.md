# Реализация Яндекс сервисов
## Контекст
Были реализоаны 2 сервиса:

- `yandex-service` - отвечает за авторизацию в Яндекс и проксирование запросов на запрос счётчиков
- `ya-metrica-service` - будет отвечать за парсинг данных в Яндекс.Метрика. Сейчас отечает только щза запрос счётчиков
Я хочу реализовать эту фишку в проекте
## Backend
Так как сервисы реализованы отдельно, а frontend может слать API запросы только к основному Backend, необходимо реализовать прокси клиент основного backend к сервису `yandex-service`. К сервису метрики не нужно, так как с ним будут общаться только другие сервисы

И кнопка, которая активирует универсальное модальное окно. Если метрика пр#вязана, то нужно вывести информацию о счётчике и аккаунте, которая доступна в БД на данный момент. #### Универсальное модальное окно
Модальное окно будет представлять собой визард из двух шагов. Первый шаг - выбор аккаунта Яндекс, второй - привязка счётчика Яндекс.Метрика. Нужно предусмотреть расширяемость второго этапа, так как потом мы реализуем возможность связи с Яндекс.Вебмастер и вторым шагом будет выбор хоста
В списке аккаунтов Яндекс на первом шаге необходимо поддержать возможность отвязать аккаунт. Так же через подтверждающее модальное окно
#### Авторизация в Яндекс
Есть метод, который даёт ссылку на авторизацию в аккаунте Яндекс. Его необходимо открывать в мини-окне. После авторизации яндекс делает редирект. Страница редиректа указана в `.env` сервиса `yandex-service`. По этому пути нам необходимо реализовать страницу, которая считает параметры ссылки и сделает POST запрос на авторизацию. После мини-окно должно быть закрыто, а список аккаунтов должен быть обновлён
Триггер для авторизации мы расположим в универсальном модальном окне. В списке аккаунтов последним пунктом "Добавить аккаунт"ед# к##
