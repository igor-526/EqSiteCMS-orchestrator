# Добавление роли SEO
## Контекст
Был выполнен ряд задач, направленных на реализацию SEO сервиса. Система прав даёт доступ ко всему функционалу пользователю с ролью администратора
Необходимо реализовать новую роль, которую и применить к функционалу платфоромы
## Выполненные задачи
Ориентируйся на следующие задачи и оставленные после них артефакты при планировании

## Задача
### Сидирование роли
Посмотри в основном backend механизм сидирования. Добавь туда новую роль для SEO. Для заполнения UUID используй генератор, а не придумывай по маске
### БД
Создай тестового пользователя с паролем как у всех остальных пользователей
### Skill
Skill для SMOKE тестирования содержит доступных пользователей для тестирования с разными ролями. Добавь туда созданного тестового пользователя
### Backend
Защити все SEO эндпоинты, чтобы они были доступны только пользователям с ролью SEO
### CMS Frontend
Раздел SEO должен показываться пользователю только с ролью SEO. Страница по прямому пути так же должна быть защищена
