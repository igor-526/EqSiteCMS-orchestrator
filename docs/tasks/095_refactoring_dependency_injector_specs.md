# Переход с depends на dependency_injector
## Контекст
В сервисе `yandex-service` реализована эталонная структура использования dependency-injector
## Задача
Давай задекларируем паттерны использования dependency injector и полный отказ от depends
Нам нужно составить инструкцию в howto по тому, как его правильно использовать и как неправильно использовать зависимости (то есть то, что есть сейчас в остальных сервисах)
Затем нам нужно будет составить план работ в виде openspec change на каждый сервис. Проанализируй каждый сервис и составь openspec change на приведение к корректному виду
Для анализа эталонного перехода смотри diff ветки `feature/di` сервиса `yandex-service`
Также нужно проконтроллировать наличие зависимости `dependency-injector` в каждом сервисе и шаблонировать его в `fastapi-template`.
