# Контекст
Мы подготовились к разработке сайта для конюшни. Теперь нам необходимо начать его реализовывать
Начнём со скелета - схемы страниц и компонентов
# Источники
`docs/sites/inlove/scheme.md` - схема сайта
`docs/sites/inlove/design_system_specification.md` - спецификация дизайна (перенесена в агентскую инструкцию в задаче 068)
`docs/parsings/ksk.inlove/` - вся доступная информация
`docs/sites/inlove/components.md` - необходимые для реализации UI компоненты
`docs/sites/inlove/seed.sql` - сид данных БД. Был загружен
# Задачи
## Реализация UI компонентов
Используя спецификацию дизайна необходимо реализовать в корневом `src/ui/` все компоненты
## Страницы
Используя схему необходимо реализовать пустые страницы на соответствующих путях
В качестве содержимого давай сделаем заглушку, которая говорит о том, что раздел пока что находится в разработке
# Header и footer
В соответствие со схемой реализуй в шаблоне всех страниц header и footer. То есть в результате у нас все страницы должны содержать этот header и footer, а также информацию о том, что страница находится в разработке
# Форма обратного звонка
В соответствие со схемой реализуй кнопку обратного звонка, которая может быть расположена в любом месте сайта. Используй zod для валидации данных
# Промежуточная заметка
Промежуточно выявлены следующие недостатки:
## Header
### Логотип
Замени надпись "ИНЛав" логотипом. Перемести его в статику
### Меню
Сделай выпадающее меню и назови его "Услуги", в которое включи следующие пункты:
- Занятия
- Прогулки
- Постой
## Footer
### Логотип
Замени надпись "ИНЛав" логотипом. Перемести его в статику
### Меню
Меню должно быть согласовано с меню в Header после правок
Уменьши расстояние между пунктами меню, чтобы Footer был компактнее
### Контакты
1. ВКонтакте переименуй на VK
2. Установи 3 иконки для трёх контактов. Возьми их с главной страницы
3. Все ссылки должны открываться в новых вкладках
## Форма обратного звонка
Убери информацию о странице с формы обратного звонка
