# Описание бага
На CMS Frontend есть модальное окно для редактирования лошади
Оно находится в разделе "Лошади", вкладка "Лошади". Можно вызвать нажатием на запись в таблице в режиме редактирования или при нажатии на кнопку создания новой лошади. В этом модальном окне есть поле для выбора масти лошади. Оно напрямую завязано на том, какие масти на данный момент загружены в этом же разделе на вкладке "Масти". Если выбранной масти нет в списке вкладки, то вместо неё подставляется UUID
# Задача
В DTO лошади приходит полное DTO масти. Используй его для подстановки значения. state другой вкладки не должен использоваться в этом селекторе
# Попутно
Посмотри ещё логику работы соседних селекторов породы и владельца на наличие этого бага
# Поиск
Эти селекторы обладают поиском. Проанализируй, что эти селекторы используют исключительно серверный поиск. Никакого клиентского поиска в списках, где присутствует пагинация
