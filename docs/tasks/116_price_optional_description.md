# 116 — Необязательное описание цены (услуги)

## Исходный запрос

При создании/редактировании услуги описание ошибочно обязательно. Пользователь сообщил: `PATCH /api/prices/3c57bf0c-5219-4343-95d3-85a42c07f7c5` с пустым описанием возвращает `400 {"detail":"Описание цены не может быть пустым"}`. «Это некорректное поведение. Пустое описание допускается».

Это наблюдение пользователя, не результат runtime-проверки Planner.

## Acceptance и ограничения

- Создание и изменение price с `description=""` разрешены.
- Отсутствующее описание при PATCH не должно стирать сохранённое значение; обработка `null` сохраняет существующий контракт.
- Сервис — `services/backend`; форма CMS проверяется точечно, без необоснованного UI diff.
- Права Public Read / Protected Write, другие поля, группы цен, horse services, схема БД и межсервисные контракты не изменяются.
- На этапе PLAN-1 создаются только артефакты; реализация — после approval пользователя. Approval не разрешает setup/teardown PostgreSQL или запись в исходную production-услугу.

Единственный изменяемый план: `openspec/changes/fix-price-optional-description/`.
