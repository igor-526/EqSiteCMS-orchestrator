# Контекст
В задаче `046_renaming_horse_code` мы выполняли доработку модели лошади. Теперь нам нужно изменить данные в production БД. В виде миграции этого делать не нужно, так как это одноразовая операция под одного клиента
# Задача
В файле `docs/tasks/047_renaming_horses_script/horse.json` содержится дамп production базы данных лошадей, над которыми нам нужно поработать
В результате миграции с задании 046 у нас поле `code` поменялось на поле `pedigree_name`
Твоя задача для каждой лошади оценить `name` на наличие кодов родословной и подготовить файлы для изменения
Коды родословной могут выглядеть как код страны или как идентификатор по типу `A 15`, `A23`, любая буква с цифрами, может выглядеть как римская цифра
Исходный файл `horse.json` не редактируй, он только для чтения
Создай новые файлы со структурой:
```json
[
	{
		"id": "UUID лошади для идентификаиции",
		"name": "Новая кличка лошади без дополнительных кодов",
		"pedigree_name": "Исходный name лошади"
	}
]
```
Нам будут нужны следующие файлы:
- `to_change.json` - обработанные тобой лошади с изменением `name` и `pedigree_name`
- `to_check.json` - лошади, в кличке которых ты не уверен
- `unchanged.json` - только выбранные поля лошадей, которые мы не трогаем
После работы остановись, я буду вручную проверять эти файлы и потом проинструктирую далее
# Примеры
- `{"name": "Colne Hyperion (GB)"}` -> `{"name": "Colne Hyperion", "pedigree_name": "Colne Hyperion (GB)"}`
- `{"name": "Colne Helena (GB)"}` -> `{"name": "Colne Helena", "pedigree_name": "Colne Helena (GB)"}`
- `{"name": "Пиколо (GER)"}` -> `{"name": "Пиколо", "pedigree_name": "Пиколо (GER)"}`
- `{"name": "Pergola II 6/86"}` -> `{"name": "Pergola", "pedigree_name": "Pergola II 6/86"}`
- `{"name": "Mocca A 451"}` -> `{"name": "Mocca", "pedigree_name": "Mocca A 451"}`
