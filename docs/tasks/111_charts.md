# Перенос на новую архитектуру
# Контекст
Была полностью потеряна инфраструктура. На новый кластер были взяты ноды как amd64, так и arm64
## Задачи
Ничего не применять и не релизить
За всем буду следить самостоятельно. Необходимо только доработать
Можешь использовать документацию кластера в `/srv/EqCMS_Infra/docs` и использовать `kubectl` в read-only режиме

### Доработки образов
По каждому сервису, где есть helm чарты и .github workflow необходимо реализовать возможность сборки и запуска как на arm, так и на x86 архитектуре
### Новые чарты
Необходимо написать github workflow и helm чарты для следующих сервисов
- `seo-service`
- `yandex-service`
- `ya-metrica-service`
