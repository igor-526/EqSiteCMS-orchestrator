# Новый пайплайн
## Написание задачи
Я буду продолжать писать изначальные задачи в `docs/plans` и отдавать файл задачи агенту как отправную точку
## Планирование
В первую очередь задача отправляется в `propose`.  `explore` активируется только если об этом явно попросить. Далее OpenSpec составляет артефакты. Пауза для их изучения и ответов на открытые вопросы обязательна. При планировании задач обязательно делить их таким образом, чтобы их могли выполнять субагенты. Агенту больше нет необходимости создавать в `docs/plans` описание задач для реализации. Всё создаётся в артефактах OpenSpec
## Реализация
Для реализации каждой задачи необходимо в обязательном порядке использовать соответствующего профильного агента. Для реализации необходимо создавать субагентов. Помни, что ты - только роутер. При реализации не допускается отдавать большое количество задач одному субагенту. Необходимо разбить задачи по зонам выполнения и оценить контекстные возможности исполняющей модели. QualityGate по прежнему обязан после своей работы оставить репорт в `docs/reports`
## QualityGate
После выполнения всеми агентами всех задач выполняется один общий QualityGate. По результатам QualityGate выполняется доработка.
