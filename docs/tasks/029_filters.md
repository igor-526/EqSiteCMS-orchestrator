# Контекст
На некоторых страницах и вкладках есть блок шапки с пагинацией. Там же есть фильтры. Некоторые фильтры расположены некорректно и дублируют друг друга. Наша задача переместить все фильтры, для которых есть отдельная колонка в эту колонку, а для которых колонки нет, оставить
# Раздел "Лошади"
## Вкладка "Лошади"
### Фильтр "База"
Фильтр представлен в виде отдельного селектора в блоке с пагинацией, хотя под эту информацию есть отдельная колонка. Необходимо перенести фильтр в соответствующую колонку в шапку таблицы
### Фильтр "Породы"
Данный фильтр есть в соответствующей шапке таблицы. Отдельный селектор из шапки необходимо удалить
### Фильтр "Масти"
Данный фильтр есть в соответствующей шапке таблицы. Отдельный селектор из шапки необходимо удалить
### Фильтр "Владельцы"
Фильтр представлен в виде отдельного селектора в блоке с пагинацией, хотя под эту информацию есть отдельная колонка. Необходимо перенести фильтр в соответствующую колонку в шапку таблицы
### Фильтр "Пол"
Данный фильтр есть в соответствующей шапке таблицы. Отдельный селектор из шапки необходимо удалить
### Фильтр "Услуги"
Данный фильтр представлен в виде колонки, в которой рендерится количество связанных услуг. Фильтр находится в шапке таблицы. Необходимо избавиться от колонки и вынести фильтр в блок с пагинацией
# Доработка агентов
Необходимо доработать агента `agents/frontend.md` таким образом, чтобы агент больше не реализовывал дублирующиеся фильтры. Логика простая: все доступные фильтры находятся в колонках таблицы через шапку. Если подходящей для фильтра колонки нет, то фильтр необходимо выносить в отдельный Select в блок, в котором реализована пагинация
